# Baselines

Third-party repositories are **not vendored** into this package. Clone them separately and preserve their licenses.

Recommended audit order:

1. DiGress
2. ConStruct
3. GraphARM
4. TopoDiffusionNet
5. TopoCellGen
6. SEDD / MD4
7. DeFoG

The final paper should report baseline versions/commits and use common dataset splits and evaluation protocols whenever feasible.
