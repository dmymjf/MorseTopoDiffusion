# Method sketch: Cubical Morse Event Diffusion

## State

For a binary defect mask `X`, construct its finite cubical complex `K(X)` containing all active unit squares and their faces.

At corruption time `t`, the state is not required to be a binary image:

`K_t = (V_t, E_t, F_t)`.

## Regular operator

Let `sigma^p` be a free face of a unique coface `tau^{p+1}`. An elementary collapse is

`K -> K \ {sigma,tau}`.

This is a homotopy equivalence, therefore Betti numbers and component-wise topology are unchanged.

## Critical operator

At a state with no free pair:

- an exposed critical 1-cell can be removed if it preserves `beta0` and lowers `beta1` by one;
- an isolated critical 0-cell can be removed if it lowers `beta0` by one and preserves `beta1`.

For planar complexes define topological complexity

`C(K)=beta0(K)+beta1(K)`.

Regular events satisfy `Delta C=0`; critical events satisfy `Delta C=-1`.

## Forward generator

For admissible regular events `R(K)` and critical events `T(K)`, a CTMC form is

`Q_t f(K) = sum_{e in A(K)} lambda_e(K,t) [f(T_e K)-f(K)]`

where `A(K)=R(K)` if regular collapses exist, otherwise `A(K)=T(K)`.

The reference implementation uses a state-dependent clock and stochastic selection among valid elementary collapses. The exact hazard parameterization is deliberately treated as secondary to the event algebra and should be ablated.

## Reverse event algebra

Reverse generation starts at the empty complex and predicts one of:

- `R+`: elementary expansion (inverse free-face/coface pair);
- `H+`: critical 1-cell attachment creating one loop;
- `C+`: critical 0-cell birth creating one component.

A scalable implementation can predict a macro event consisting of a sequentially valid list of elementary expansions.

## Key theoretical property to prove/verify

For any forward trajectory generated by the reference operator:

1. every regular event is a homotopy equivalence;
2. every critical event changes `beta0+beta1` by exactly -1;
3. number of critical events from `K_0` to empty is exactly `beta0(K_0)+beta1(K_0)`;
4. reverse events are well-defined inverses when their event support/order is retained.
